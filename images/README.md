# Dossier des visuels

Déposez ici les captures d’écran et les images destinées au portfolio.

## Organisation conseillée

- `projet-01-accueil.png`
- `projet-01-mobile.png`
- `projet-02-accueil.png`

Pour afficher une image dans le README principal, utilisez par exemple :

```md
![Aperçu du projet 01](./images/projet-01-accueil.png)
```

Avant de publier une image, vérifiez qu’elle ne contient pas de données personnelles ou d’informations confidentielles et que vous avez l’autorisation de la partager.
